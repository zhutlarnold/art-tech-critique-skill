# v1.1.0 · 从概念优先改为视觉优先

试用《Autonomous Trap 001》后，用户提出作品需要美感和震撼感。原规则能写出形式、技术与生活哲思，却缺少在写稿前淘汰视觉不适配选题的环节。

现在自动选题先看真实原图，检查美感、震撼感、手机首图辨识度、批判关系与图片可用性。思想深度不抵消视觉弱项；照片未查看则标为待评估。合格候选不足时明确数量，不凑满。

盐圈案例在现有两张原图条件下退出默认发布推荐，保留作已知失败回归案例。抽象艺术仍可入选；明确指定作品分析时说明局限后继续。油田稿与ImageNet Roulette认可稿保留，但旧范例不自动通过新视觉标准。

标题的事件断言、拍摄视角对机器视野的推断、生活类比的技术边界也加入核查，避免用戏剧性文字掩盖画面不足。

新增第12项独立功能“视觉适配与首图筛选”，同步候选选题、完整调用、验收、普通聊天提示词和测试请求。研究证据、查重、真实原图与自然语言要求继续适用。

本次没有改写已认可两篇全文，没有生成替代图，也没有把主观视觉筛选称作流量保证。新规则的跨AI重新试用和受众效果仍待验证。
